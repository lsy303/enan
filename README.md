# عِنان | إسطبلك بيدك

نظام عربي لإدارة الإسطبلات، مبني على Firebase. نسخة واحدة تخدم كل الإسطبلات؛ اسم كل إسطبل وبياناته محفوظة في قاعدة البيانات.

## الملفات

| الملف | الوصف |
|---|---|
| `index.html` | صفحة التعريف |
| `app.html` | التطبيق: الدخول والتسجيل والإدارة. ومع `?demo` يعمل كنسخة تجريبية محلية |
| `admin.html` | لوحة المشرف: تفعيل الإسطبلات وتجديدها وإيقافها |
| `firestore.rules` | قواعد الأمان |
| `tests/rules.test.mjs` | اختبار قواعد الأمان (23 سيناريو) |

## خطوات الإعداد (مرة واحدة)

1. **قواعد الأمان:** Firebase Console ← Firestore Database ← Rules ← الصق محتوى `firestore.rules` ← Publish.
2. **النطاق المصرّح به:** Authentication ← Settings ← Authorized domains ← Add domain ← `lsy303.github.io`.
3. **حساب المشرف:**
   - Authentication ← Users ← Add user (بريدك وكلمة مرور).
   - انسخ الـ User UID.
   - Firestore ← Start collection ← المعرّف: `admins` ← Document ID: الـ UID ← أضف حقلًا `name` بأي قيمة ← Save.
4. **(اختياري) لغة رسائل البريد:** Authentication ← Templates ← غيّر لغة القوالب إلى العربية.

## مسار العميل

1. يسجّل من `app.html` ← يُنشأ إسطبله **بانتظار التفعيل**.
2. تفتح `admin.html` ← **تفعيل تجربة 14 يومًا** أو **تفعيل سنة** بعد الدفع.
3. عند اقتراب الانتهاء (7 أيام) يظهر للمالك تنبيه مع زر واتساب للتجديد.
4. بعد الانتهاء: يقرأ بياناته ويصدّرها فقط حتى التجديد.

## الصلاحيات

| | المالك | الموظف |
|---|---|---|
| المتدربون والحضور والمواعيد والإيواء | ✅ | ✅ إضافة وتعديل |
| الحذف | ✅ | ❌ |
| الباقات والدفعات | ✅ | ❌ |
| المصاريف والتقارير والنسخ الاحتياطي | ✅ | ❌ |
| الإعدادات والموظفون | ✅ | ❌ |

## نقل بيانات من النسخة القديمة

من النسخة القديمة: ⋮ ← تنزيل نسخة ← ملف JSON.
في عِنان: ⋮ ← استيراد نسخة احتياطية ← اختر الملف.

## اختبار قواعد الأمان

```bash
npm i -D firebase-tools @firebase/rules-unit-testing firebase
npx firebase emulators:exec --only firestore --project demo-enan "node tests/rules.test.mjs"
```
